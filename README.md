# Школьный сайт (локальная версия)

## Запуск
```
python -m venv venv
venv\Scripts\activate        # Windows  (Linux/Mac: source venv/bin/activate)
pip install -r requirements.txt
python manage.py makemigrations accounts school core news library
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```
Сайт: http://127.0.0.1:8000/  Админка: http://127.0.0.1:8000/admin/

## Что делать в админке
1. Создать группу «Библиотекарь» (по желанию) и выдать права на Book, BookCopy, Loan.
2. Добавить категории, книги и экземпляры книг.
3. В разделе «Выдачи» оформить выдачу книги пользователю.

## Роли и вход
Вход начинается с выбора роли: Учитель, Родитель, Ученик(ца).
1. В админке откройте пользователя (Пользователи → создать/изменить).
2. Внизу страницы в блоке «Профиль» выберите роль. Для родителя отметьте детей.
3. Сотрудники (галочка «Статус персонала») могут войти через любую роль.

## Кабинеты (как в Э-Күндөлүк)
У каждой роли свой кабинет и своё боковое меню:
- **Ученик:** уроки на сегодня, расписание, оценки по предметам, книги на руках.
- **Родитель:** карточки детей (средний балл, оценки, книги), расписание и оценки каждого ребёнка.
- **Учитель:** свои уроки, классы, выставление оценок.
- **Библиотека** есть в меню у всех ролей (каталог и «Мои книги»; у родителя «Книги детей»).

## Быстрая проверка с демо-данными
```
python manage.py seed_demo
```
Создаст teacher1, parent1 и student1 (пароль demo12345), класс 9А, расписание, оценки, книгу и новость.
Войдите под каждым, выбрав соответствующую роль на странице входа.

## Вручную (в админке)
1. Классы и предметы: Школа → Классы, Предметы.
2. Расписание: Школа → Расписание.
3. Пользователь → блок «Профиль»: роль, класс (для ученика), дети (для родителя).

## Сброс пароля и привязка Gmail
- Пользователь открывает **профиль** (клик по имени в боковом меню), вводит Gmail, получает письмо со ссылкой и подтверждает. После этого почта привязана.
- На странице входа есть ссылка **«Забыли пароль?»**: вводится привязанная почта, приходит ссылка на новый пароль (действует 1 час).
- **Локальная проверка без Gmail:** письма печатаются в терминале, где запущен `runserver`. Скопируйте ссылку из терминала в браузер.
- **Настоящая отправка через Gmail.** В аккаунте Google включите двухэтапную проверку и создайте «Пароль приложения»
  (https://myaccount.google.com/apppasswords). Обычный пароль от Gmail не подойдёт. Затем задайте переменные окружения
  перед запуском:
  ```
  Windows (cmd):   set EMAIL_HOST_USER=school@gmail.com
                   set EMAIL_HOST_PASSWORD=пароль_приложения_из_16_символов
  Linux / Mac:     export EMAIL_HOST_USER=school@gmail.com
                   export EMAIL_HOST_PASSWORD=пароль_приложения
  ```
  Письма будут уходить с этого адреса. Не записывайте пароль приложения в код и не выкладывайте его на GitHub.

## Настройки (иконка-ползунки внизу бокового меню)
- **Внешний вид:** светлая или тёмная тема, сворачивать меню по умолчанию, отключить анимации (хранится в браузере).
- **Аккаунт:** имя и фамилия, привязка Gmail, смена пароля.
- **Уведомления на почту:** новые оценки (уходят ученику и его родителям сразу после выставления) и напоминания о книгах.
- Напоминания о книгах рассылает команда `python manage.py remind_books` (книги со сроком «завтра» и просроченные).
  Запускайте её вручную или по расписанию (cron, планировщик задач). Для отправки почты нужен Gmail (см. выше).
- После этого обновления выполните: `python manage.py makemigrations accounts` и `python manage.py migrate`.

## Расширенные настройки (обновление)
После обновления файлов выполните: `python manage.py makemigrations accounts library` и `python manage.py migrate`.

- **Внешний вид:** тема, размер текста (мелкий, обычный, крупный), меню, анимации.
- **Профиль:** фото (показывается в боковом меню), родитель выбирает ребёнка по умолчанию, учитель выбирает класс по умолчанию для журнала оценок.
- **Уведомления:** оценки, напоминания о книгах, сводка за неделю. Рассылка: `python manage.py remind_books` и `python manage.py weekly_digest`
  (запускайте вручную или по расписанию).
- **Безопасность:** двухфакторный вход (коды Google Authenticator и подобных, вводятся вручную по ключу),
  выход на всех других устройствах, история последних входов.
- **Данные:** выгрузка своих оценок и выдач книг в CSV (открывается в Excel), отключение аккаунта (только если нет невозвращённых книг;
  вернуть аккаунт может администратор в админке, поле «Активный»).
- **Библиотека:** срок выдачи по умолчанию задаётся в админке (Библиотека → Настройки библиотеки). Если поле «Вернуть до» в выдаче пустое, срок ставится сам.
- Двухфакторный вход доступен аккаунтам с ролью. Сотрудники без профиля входят без кода. Если потерян телефон с кодами,
  администратор может снять защиту: в админке у пользователя в блоке «Профиль» снять галочку «Двухфакторный вход».

## Домашние задания, посещаемость, библиотекарь, уведомления
После обновления: `python manage.py makemigrations accounts school library` и `python manage.py migrate`
(для свежих демо-данных: `python manage.py seed_demo`, добавится librarian1 с тем же паролем demo12345).

- **Домашние задания.** Учитель добавляет задание классу (с файлом по желанию), ученики и родители видят его в кабинете
  и получают уведомление.
- **Посещаемость.** Учитель выбирает класс, предмет и дату и отмечает статус каждого ученика (присутствует, опоздал,
  отсутствует, уважительная причина). О пропуске и опоздании родителю приходит уведомление. Ученик и родитель видят сводку и список пропусков.
- **Библиотекарь** (четвёртая кнопка на странице входа). Свой кабинет без админки: выдача книги (читатель + экземпляр + срок),
  приём возврата, должники, добавление книги с экземплярами. Срок по умолчанию берётся из «Настроек библиотеки» в админке.
  Роль выдаётся в админке: пользователь → блок «Профиль» → роль «Библиотекарь».
- **Уведомления** внутри сайта: колокольчик в боковом меню со счётчиком непрочитанных (новые оценки, задания, пропуски, выданные книги).

## Кыргызский язык
- Переключатель языка: кнопка **KY / RU** внизу бокового меню, выпадающий список «Русский / Кыргызча» на страницах входа и в настройках.
  Выбор запоминается в браузере (cookie «lang»).
- Как устроено: тексты сайта написаны по-русски, а для кыргызской версии `apps/core/middleware.py` заменяет известные фразы
  в готовой странице по словарю `apps/core/ky.py`. Перевод охватывает меню, вход, кабинеты, библиотеку, настройки и сообщения сайта.
- **Исправить или улучшить перевод**: откройте `apps/core/ky.py` и измените кыргызский текст в нужной паре
  `("русский текст", "кыргызский текст")`. Перезапустите сервер.
- **Новая надпись на сайте.** Если вы добавили новый русский текст в шаблон, добавьте для него пару в `PAIRS`,
  иначе в кыргызской версии он останется по-русски.
- Письма (сброс пароля, оценки, напоминания) пока отправляются по-русски.
- Перевод сделан автоматически, его стоит показать учителю кыргызского языка и поправить формулировки в `ky.py`.
